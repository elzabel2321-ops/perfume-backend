# 🌸 Perfume Shop

A full-stack e-commerce perfume shop application built with
Node.js, Express.js, MongoDB, JavaScript and TypeScript.

## ✨ Features

- 🔐 User Registration & Login
- 👤 User Authentication
- 🌸 Perfume Product Management
- 🔍 Product Search
- 🏷️ Product Categories
- 🛒 Shopping Cart
- 📦 Order Management
- 💳 Payment Integration
- 🔔 Notifications
- 👨‍💼 Admin Dashboard
- 📦 Inventory Management
- 📊 Analytics

## 🛠️ Technologies

### Backend

- Node.js
- Express.js
- MongoDB
- REST API
- JWT Authentication

### Frontend

- JavaScript
- TypeScript
- CSS

### Development Tools

- Git
- GitHub
- VS Code
- npm
